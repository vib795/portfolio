This post is a template. It is set to `draft: true`, so it shows up while you
run `npm run dev` and never appears on the live site. Copy it, rename it, flip
the flag, and it publishes.

Everything below is a reference for what the renderer supports.

## Headings and text

Headings from `##` down to `####` are styled. Regular prose supports **bold**,
*italic*, `inline code`, and [links](https://singhcodes.dev) that underline on
hover.

> Blockquotes get an accent rule on the left. Good for pulling out the one
> sentence you want someone to remember.

## Code

Fenced blocks are syntax-highlighted with Shiki, and the theme follows the
site's light/dark toggle automatically.

```python
async def summarize(chunks: list[str]) -> str:
    """Fan out, then reduce. The model never sees the whole corpus at once."""
    partials = await asyncio.gather(*(model.summarize(c) for c in chunks))
    return await model.summarize("\n\n".join(partials))
```

## Tables

| Frontmatter | Required | Notes                                   |
| ----------- | -------- | --------------------------------------- |
| `title`     | yes      | Shown on the card and as the `<h1>`      |
| `date`      | yes      | `YYYY-MM-DD` — the build fails if wrong  |
| `excerpt`   | yes      | Card copy and the meta description       |
| `tags`      | no       | Rendered as chips                        |
| `draft`     | no       | `true` hides it from production          |

## Images

Drop images in `public/blog/` and reference them from the site root:

```md
![Alt text that actually describes the image](/blog/architecture.png)
```
