Every developer knows the thrill of seeing that colorful GitHub contribution chart at the end of the year — a visual mosaic of late-night coding, debugging marathons, and breakthrough moments. But what if you could capture your coding journey, every single file save, and turn each one into a digital milestone? Meet Flaunt GitHub, a Visual Studio Code extension that does exactly that.

Capture Every Moment

Flaunt GitHub tracks your coding activity by logging each file save event and, at regular intervals, commits an aggregated summary of your work to a dedicated GitHub repository. No more lumping all your changes together — instead, each commit is a curated snapshot of your progress. And with seamless installation via the Visual Studio Marketplace, you can start flaunting your progress with just a click.

Beyond the Contribution Chart

GitHub isn’t just a code repository — it’s a living diary of your evolution as a developer. While most developers flex their vibrant contribution graphs, Flaunt GitHub digs deeper by creating a dedicated timeline of your daily coding activity. It captures the small yet significant moments — every file save, tweak, and refinement — building a narrative of your journey throughout the year.

How It Works

Continuous Activity Logging:
Every time you save a file in VS Code (whether manually or through auto-save), the extension logs the event with a timestamp. These entries accumulate in an in‑memory summary, forming a detailed record of your day-to-day work.

Periodic Automated Commits:
Rather than cluttering your GitHub history with every individual save, Flaunt GitHub aggregates your activity and commits a summary every 30 minutes (or on a custom interval). This creates a digital diary — each commit a milestone that documents your progress.

Manual Commit Option:
Had a breakthrough or want to capture a particularly noteworthy moment? Simply trigger a manual commit from the Command Palette and instantly record that milestone.

Automated Repository Management:
On startup, the extension checks for a dedicated repository (named by default code-tracking) in your GitHub account. If the repository doesn’t exist, it’s automatically created and cloned locally — ensuring that your coding diary is safely stored in one neat place. Enhanced repository validation now ensures that your local clone is always a valid Git repository, even if issues arise during setup.

Timezone-Aware Timestamps:
No more wondering what timezone your timestamps are in! Flaunt GitHub now auto-detects your system’s timezone and formats all log entries and commit messages accordingly. And if you’d rather see a specific timezone, you can easily override the auto-detected value via settings.

Real-Time Output Channel Logging:
Stay in the loop with an integrated output channel. Every action — from file saves and log aggregation to commits and pushes — is logged in real time, giving you a transparent view of the extension’s inner workings.

Getting Started

1. Install from the Visual Studio Marketplace

  • Open Visual Studio Code.
  • Go to the Extensions view by pressing Ctrl+Shift+X (Windows/Linux) or Cmd+Shift+X (macOS).
  • Search for flaunt-github.
  • Click Install — and just like that, the extension is added to your VS Code environment.

2. Configure Your GitHub Credentials and Timezone

After installation, configure your GitHub credentials so that Flaunt GitHub can create (or use) the dedicated repository and push commits. Open your settings (via File > Preferences > Settings or by editing your settings.json) and add:

{
  "codeTracking.githubToken": "YOUR_GITHUB_PERSONAL_ACCESS_TOKEN",
  "codeTracking.githubUsername": "YOUR_GITHUB_USERNAME",
  // Optional: override auto-detected timezone, e.g., "America/New_York"
  "codeTracking.timeZone": "YOUR_DESIRED_TIMEZONE"
}
  • Replace YOUR_GITHUB_PERSONAL_ACCESS_TOKEN with a GitHub PAT that has the necessary scopes (use public_repo for public repositories or repo for private ones).
  • Replace YOUR_GITHUB_USERNAME with your GitHub username.
  • Optionally set codeTracking.timeZone to force a specific timezone; if omitted, the extension uses your system’s timezone.

3. Start Flaunting Your Code

With everything set up, Flaunt GitHub immediately begins tracking every file save. Whether through auto-save or manual saving, each event is logged with a precise, timezone-aware timestamp. Every 30 minutes, the extension aggregates these logs and commits them to your dedicated repository, turning your daily coding activity into a curated timeline of progress.
