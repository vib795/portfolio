Building such “trivial” applications that we take for granted has always been something that has had my interest. It is when you start working on such applications you realize that “Simplicity is the ultimate sophistication.”

I started on building this script when there came a time when my wife was juggling between creating pdfs from docx files, which is easy and an in-built feature of most word processing programs, but the other way around is not so much in built into a lot of applications (at least not some that I am aware of). Also, I am really unsure about how safe our data is with the online applications we end up uploading our files to.

Now that you know the motivation behind this… Python to the rescue!!!

Below is the script I came up with which runs using the following command:

python app.py <input_file> <output_file>

Here the input file can be a .pdf or a .docx file. If the first parameter is a .pdf file, the script assumes that you want to convert it to a .docx file and vice versa.

A couple of things to note here before we jump into the script:

  1. I am running this on a Mac.
  2. I am using docxtopdf library (for docx to pdf conversion) which internally relies on Microsoft Word to perform the conversion on macOS. So, I have Microsoft Word installed.

Now let us look at the script.

import os
from docx2pdf import convert
from pdf2docx import Converter
import sys

def pdf_to_docx(pdf_path: str, docx_path: str) -> None:
    """
    Convert a PDF file to a DOCX file.

    Args:
        pdf_path (str): The path to the PDF file.
        docx_path (str): The path to save the converted DOCX file.

    Returns:
        None
    
    Raises:
        Exception: If an error occurs during conversion.
    """
    # Check if the PDF file exists at the specified path
    if not os.path.exists(pdf_path):
        print(f"File '{pdf_path}' not found.")
        return

    try:
        cv = Converter(pdf_path)
        cv.convert(docx_path, start=0, end=None)  # Convert all pages
        cv.close()
        print(f"File converted to .docx successfully: {docx_path}")
    except Exception as e:
        print(f"An error occurred in converting to .docx: {str(e)}")

def docx_to_pdf(docx_path: str, pdf_path: str) -> None:
    """
    Convert a .docx file to a .pdf file.

    Args:
        docx_path (str): The path to the input .docx file.
        pdf_path (str): The path to save the output .pdf file.

    Returns:
        None

    Raises:
        Exception: If an error occurs during conversion.
    """
    if not os.path.exists(docx_path):
        print(f"Error: File '{docx_path}' not found.")
        return
    try:
        convert(docx_path, pdf_path)
        print(f"File converted to .pdf successfully: {pdf_path}")
    except Exception as e:
        print(f"An error occurred in converting .pdf: {str(e)}")

if __name__ == "__main__":
    if len(sys.argv) != 3:
        print("Usage: python script.py <input_file> <output_file>")
        sys.exit(1)

    input_file = sys.argv[1]
    output_file = sys.argv[2]

    if input_file.endswith(".docx") and output_file.endswith(".pdf"):
        docx_to_pdf(input_file, output_file)
    elif input_file.endswith(".pdf") and output_file.endswith(".docx"):
        pdf_to_docx(input_file, output_file)
    else:
        print("Unsupported file type type.")

Here we have a pdf_to_docx method which, as the name suggests, converts a .pdf to a .docx file.

This first checks if the path passed as an argument exits and then tries converting the .pdf file to a .docx file.
